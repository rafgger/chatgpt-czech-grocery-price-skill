# Czech Grocery Price Comparison Skill

A ChatGPT and Codex skill that compares grocery prices across
nearby Czech supermarkets, Rohlík.cz and Košík.cz.

It verifies product prices, package sizes, promotion conditions
and complete basket totals.

## Example

Compare butter and milk near Osov.

## Installation

Ask ChatGPT or Codex to install the skill from:

https://github.com/rafgger/chatgpt-czech-grocery-price-skill/compare-czech-grocery-prices

## Requirements

The skill requires access to web search for current prices.
Interactive browser access may be needed to verify delivery
availability and location-specific offers.
